Simple Calculator
A minimal interactive calculator implemented in Python.

Usage:

Run: python3 calculator.py
The program shows a menu. Choose an operation (by number or symbol), then enter two numbers.
Commands:
1 or + : add
2 or - : subtract
3 or * : multiply
4 or / : divide
5 or ^ : power (a ** b)
6 or % : remainder
7 or # : terminate
8 or $ : reset (back to menu)
